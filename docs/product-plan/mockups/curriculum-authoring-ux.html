Week Builder — modules and activities
Inside one week. Each module is a card containing a flat list of activity rows. Up/down arrow buttons on each row for reordering (drag-and-drop deferred to v2). Each module has its own "+ Add activity" button; a full-width "+ Add module" sits at the bottom.

About this file. These are planning-stage mockups, not final UI designs. They capture the decisions from the 2026-04-20 curriculum authoring UX session in a single place for later reference.

Real UI will be built against the QAcademy brand and can refine layout, spacing, and typography. The structural decisions (hierarchy, views, flows, fields per activity type, reordering model, publish model) are what matter here.

See mynclex/docs/product-plan/curriculum-authoring-ux.md for the full written plan.
