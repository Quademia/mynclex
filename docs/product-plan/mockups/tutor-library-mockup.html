MyNclex — Tutor Library · Mockup

Visual companion to tutor-library.md. 12 block types, full editor + reader experience.

Last updated: 2026-05-11 · Pure visuals · No real data, no real functionality · Terminology synced with the curriculum architecture rework — Library Notes attach to units, rendered as "Week N" or "Module N" per the programme's unit_label (a separate tutor choice, decoupled from delivery mode). Loose under a unit OR inside a curriculum block. Both delivery modes (tutor-led and self-paced) ship in v1; the screen labels "Week activity" etc. demonstrate the tutor-led + Week-labelled case.

What changed in this version. Added 7 new block types (List, Quote, Table, Callout with 5 variants, Drug card, Lab values table, plus the existing Heading/Paragraph/Image/PDF/Video/Embedded question = 12 total). Editor gained an inline formatting toolbar and a block-insertion popover. Student read view now renders all the new structured blocks. New screen: "Add block" popover demonstrating slash-command UX. Latest: student read view now has a Contents panel on the left auto-built from the note's headings — click to jump, scroll-spy highlights active section, reading progress sits at the bottom of the panel.
