**What shipped (to the session branch).** `MATRIX_MR` — Matrix Multiple
Response, a new **self-contained** NGN item type. A rows × columns grid where
each row has **one or more** correct columns (checkbox per cell), scored
SATA-style per row. Mirror of the existing `MATRIX` (radio, exactly one per
row) — legacy `MATRIX` left 100% untouched. First end-to-end use of the
"Adding a new question type — wiring checklist" captured last session.

**Design — the 4 open questions settled one-at-a-time with Sam** (BUILD_LIST +
`questions-and-wrappers-rebuild.md` carry the full write-up):

- **Q1 — can a row have zero correct?** No — **require ≥1 correct per row.**
  This was the hard one; grounded it in a **web check of the NCSBN spec**
  (paywalled pages 403'd, but several independent sources converge): Matrix MR
  = 4–10 rows, 2–3 cols, per-column +/- scoring floored at 0, and crucially the
  real exam **forces the student to tick ≥1 box per row to proceed** — which
  makes an all-false row literally unanswerable. So real items always have ≥1
  correct per row. Surfaced as a clear editor block, not a silent fail.
- **Q2 — scoring:** **SATA-style per row.** New `scorePerRowMulti` in
  `lib/scoring/functions.ts` runs the existing `scorePlusMinus` per row (+1
  correct / −1 wrong, floored at 0 within the row), summed across rows. Max
  marks = total correct cells across all rows (a row with 2/1/3 correct → 6
  marks). `is_correct` (full credit) only when every row is exactly right.
- **Q3 — submit gate:** **hard gate** — the student must pick ≥1 per row; the
  runner's submit hint **names the still-empty rows** ("row 2, 4 still empty").
- **Q4 — bounds:** mirror MATRIX exactly (hard **2–10 rows / 2–6 cols**) + an
  advise > block amber advisory toward the NGN norm (4–10 rows, 2–3 cols).

**Files (mirrors of MATRIX; no stem-doc — matrix has no markers):**
`lib/bank/editors/matrix-mr-editor.tsx` (checkbox cells, `correct: rowId →
columnId[]`), `lib/bank/editors/matrix-mr-row-mapper.ts`,
`lib/bank/parsers/matrix-mr.ts` (≥1-correct-per-row, bounds), and
`lib/practice/runner/types/matrix-mr.tsx` (checkbox grid, ≥1-per-row submit
gate) + the new `scorePerRowMulti` scorer.

**Wire-up (per the checklist).** The 4 runtime whitelists tsc can't catch
(picker `ENABLED_TYPES` · bank-list `EDITABLE_TYPES` · save `SUPPORTED_TYPES` ·
filter `QTYPE_OPTIONS` length-guard); all tsc-caught switches/maps
(classifications · types · scoring · runner render + submit-gate + labels ·
