### Alignment first (no code until locked)
Sam opened by checking we both remembered last session's decisions. Walked
back through **"Option C"**: an attached note/shelf is a **first-class
`nclex_programme_activities` row** (types `LIBRARY_NOTE` / new `SHELF`)
**AND** keeps its `nclex_tutor_library_note_attachments` row, joined by
`activity_id`. For shelves specifically the two load-bearing facts:
**(1) a shelf is ATOMIC** — ONE activity + ONE attachment (`shelf_id` set,
`note_id` NULL), never one-activity-per-note; **(2) completion is
DERIVED** — a rollup of member-note `marked_done_at`, no progress row.
Key realisation that made the migration tiny: the attachment table has had
`shelf_id` + `skipped_note_ids` + the `note_id` XOR `shelf_id` CHECK since
11.1, and `activity_id` since 11.11a — so **the only schema change is
adding `'SHELF'` to the activity-type CHECK.**

Then settled, in plain terms with Sam, four design points:
- **`skipped_note_ids`** = "Hide in this unit" — a per-placement, reversible
  local trim that never touches shelf membership.
- **Tutor card stays uniform** (like every other activity); all shelf detail
  + the member-notes-with-hide controls live in the **edit modal** — matches
  how every activity behaves (Sam's call, diverging from the CD prototype's
  special card).
- **Mixed visibility — "Option A" (full).** A shelf can hold notes whose own
  visibility excludes the target programme. Warn at attach ("N of M won't be
  visible here"); in the modal show a DISTINCT state "Not visible to this
  programme · Make visible here" (never conflated with "Hidden here ·
  Unhide"). "Make visible here" = the same op as editing the note to add the
  programme (inserts a `_note_visibility` row; only ever widens). Sam's
  framing: mixed-visibility is rare/self-inflicted (a reusable shelf carrying
  programme-scoped notes contradicts the shelf's purpose), so we don't
  over-invest — warn + read-the-state + one-click fix is plenty.
- **Live membership** — the shelf reads members at render time, so adding a
  note in the library updates every attachment. New notes opt-out (show
  unless skipped); the skip-list keeps trimming as the shelf grows. The
  11.12c hint explains a change to students.
- **Student side**: uniform card + "N of M done"; Open → popup table-of-
  contents (each member → the 11.13a read view) + "Go to shelf" → `?shelf=`
  (verified already built in 11.14). Done is derived — no manual button.

### 11.12c — "your tutor updated this shelf" drift hint (`1e68985`)
Designed with Sam (chose **Option B** — accurate, catches adds + removes,
clears on reopen — over a no-migration heuristic). New
`nclex_library_shelf_seen` (migration `20260626130000`): per-(student,

chip clears (popup line captured to local state so it survives the refresh).
